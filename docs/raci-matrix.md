# Матрица RACI

Распределение ответственности по задачам первого этапа проекта.

- **R** (Responsible) — исполнитель
- **A** (Accountable) — ответственный за результат
- **C** (Consulted) — консультируемый
- **I** (Informed) — информируемый

| Задачи | Пшеничников А.Д. (тестирование) | Ромашкина А.Ю. (исследователь) | Свидерская В.Ю. (данные) | Сероштанов Я.К. (руководитель разработки) | Смирнов Я.В. (программист и архитектор ПО) |
|:--|:-:|:-:|:-:|:-:|:-:|
| Выбор коммуникации | I | I | I | R/A | I |
| Распределение ролей | C | C | C | R/A | C |
| Эссе | R | R | R | A | R |
| Построение матрицы RACI | C | C | C | R/A | C |
| Оформление результатов отчёта | C | C | C | R/A | C |

Для каждой задачи назначен один ответственный (A) и как минимум один исполнитель (R).
