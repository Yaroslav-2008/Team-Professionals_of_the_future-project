# Правила взаимодействия в команде

Команда «Профессионалы будущего».

## Способ коммуникации

Технологический способ — взаимодействие с помощью технических средств: компьютеров, мессенджеров.

Причина выбора: технологический способ коммуникаций экономит время и позволяет быть на связи всегда. Он фиксирует всю переписку и договорённости, так что ничего не теряется. Такие инструменты удобно сочетать с рабочими и учебными сервисами, например с СДО или системами планирования.

## Порядок работы

* **Обсуждение задач.** Задачи обсуждаются в общем чате команды, итоги фиксирует руководитель разработки.
* **Принятие решений.** Решение принимается общим согласием участников. Если согласия нет, окончательное решение принимает руководитель разработки.
* **Соблюдение сроков.** Каждый участник выполняет свою часть в срок, о возможной задержке сообщает в чат заранее.
* **Работа с репозиторием.** Каждый участник работает в своей ветке и вносит изменения в `main` только через Pull Request. Сообщения коммитов описывают суть изменения.
* **Проверка и слияние.** Pull Request проверяет другой участник команды.
