# Профессионалы будущего

Сквозной командный проект по дисциплине «Введение в профессиональную деятельность» (направление 09.03.04).

## О проекте

**Тема:** «Сервис рекомендаций фильмов по настроению».

Веб-сервис, который помогает пользователю подобрать фильм под его настроение. Итогом проекта станет прототип веб-сайта, реализующий пользовательские сценарии.
