# Профессионалы будущего

Сквозной командный проект по дисциплине «Введение в профессиональную деятельность» (направление 09.03.04).

## О проекте

**Тема:** сервис рекомендаций сериалов.

Веб-сервис, который помогает пользователю подобрать сериал для просмотра. Итогом проекта станет прототип веб-сайта, реализующий пользовательские сценарии.
